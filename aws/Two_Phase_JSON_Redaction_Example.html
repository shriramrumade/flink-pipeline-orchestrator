Two-Phase Sensitive Data Redaction for Nested JSON

Problem

A database table contains a complex nested JSON document stored in a single column. The objective is:

  1. Identify and classify sensitive data.
  2. Redact sensitive values using the classification metadata.

Input Table

IDCustomerPayload
101ABC CorpNested JSON

Payload JSON

{
  "customer":{
    "name":"John Smith",
    "ssn":"123-45-6789",
    "email":"john@gmail.com",
    "phones":[{"type":"mobile","number":"4805551234"}]
  },
  "orders":[
    {"orderId":"1001","payment":{"cardNumber":"4111111111111111","cvv":"123"}},
    {"orderId":"1002","payment":{"cardNumber":"5555444433332222","cvv":"456"}}
  ],
  "comments":"Customer called from Arizona yesterday."
}
